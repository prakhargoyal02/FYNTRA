# Use FYNTRA like an app

FYNTRA is a responsive website. These steps create a convenient browser shortcut; they do not turn it into a native banking app. Internet access is required. Demo changes are temporary unless exported.

## Android

Open the live FYNTRA address in Chrome. Open the three-dot menu, choose **Add to Home screen**, then **Create shortcut** if offered. Name it FYNTRA and add it. Menu wording varies by Chrome version. [Google's instructions](https://support.google.com/chrome/answer/15085120?co=GENIE.Platform%3DAndroid).

## iPhone

Open the website in Safari, tap **Share**, then **Add to Home Screen**. Name it FYNTRA and tap **Add**. Newer iOS versions may offer an Open as Web App option. [Apple's instructions](https://support.apple.com/en-mide/guide/iphone/iph42ab2f3a7/27/ios/27).

## Windows

Open the live address in Edge or Chrome and bookmark it for reliable access. If the browser offers an **Install this site as an app** or **Install page as app** command, use it to create a separate browser window and Start menu shortcut. Availability and menu wording depend on browser version; installation is not required to use FYNTRA.

## Everyday use

On a phone, open the sidebar navigation from the top-left menu. Cards and forms stack vertically. Detailed tables can scroll internally. Private sign-in is separate from the fictional demo. Leave Remember off on shared devices and sign out when finished. If cloud sync reports a problem, export a bundle before closing the session.

FYNTRA does not send push reminders, process payments or work offline. A home-screen icon does not change those limits.
