# FYNTRA rebuild progress

This branch restores the useful product features from the original FYNTRA while keeping the code beginner-readable.

## Included in this pass

- Overview with available cash, income, expenses, budgets, net cash flow, savings rate, net worth, subscriptions and upcoming commitments
- Transactions with income, expense and transfer support
- Search, filters, sorting, edit, duplicate and delete
- Payment methods, tags, subcategories and notes
- Accounts with transfer-aware balances
- Budgets with health bands and affordability calculator
- Bills with recurring frequencies and ledger-linked payments
- Subscriptions with pause/resume, monthly equivalent cost and ledger-linked payments
- Savings goals
- Debt tracking with principal/interest payments and reversible linked ledger entries
- Insights with category, daily, monthly and rolling-average analytics
- Planning with monthly review and timeline
- Recurring transaction schedules with duplicate-safe generation
- CSV transaction import/export
- Full ZIP backup and restore
- Deterministic fictional demo data

## Intentionally not included yet

- Supabase authentication
- Cloud synchronization
- Complex production deployment helpers
- Final UI redesign
- Final portfolio README

Those are intentionally delayed so the core finance app stays understandable.
